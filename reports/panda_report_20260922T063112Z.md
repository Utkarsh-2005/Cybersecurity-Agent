## Executive Summary

The VAmPI API, designed for educational purposes, has been found to contain multiple critical vulnerabilities that could be exploited by malicious actors. Key issues include unauthorized access to user data, excessive data exposure through debug endpoints, and the ability for anonymous users to perform administrative actions. These vulnerabilities pose significant risks to user privacy and data integrity. Immediate remediation actions are recommended to secure the API and protect sensitive information.

---

## API Overview

The VAmPI API is a deliberately vulnerable API intended for educational and testing purposes, allowing users to manage books and user accounts. It supports various authentication profiles, including anonymous access, user tokens, and admin tokens, which dictate access levels to different endpoints. However, the API's design has led to critical security flaws that must be addressed.
