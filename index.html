Reconnaissance

Crawls the target, discovers API endpoints, maps authentication schemes, and builds a surface-area inventory for downstream agents.

recon agent~15% of pipeline

API Understanding

LLM-driven analysis of discovered endpoints — infers resource relationships, data flows, and business logic from raw HTTP responses.

understanding agentLLM-powered

Threat Modeling

Generates security hypotheses based on the API surface and understanding. Maps potential vulnerabilities to OWASP categories.

threat_modeling agentLLM-powered

Test Planning

Creates targeted test cases for each hypothesis — choosing HTTP methods, payloads, and expected responses to confirm or reject threats.

test_planning agentiterative

Execution & Analysis

Runs planned tests against the live API, captures responses, and uses the LLM to determine whether each vulnerability hypothesis is confirmed.

executor agentlive HTTP calls

Report Generation

Compiles all confirmed findings into a structured security report with severity ratings, OWASP mappings, and remediation guidance.
